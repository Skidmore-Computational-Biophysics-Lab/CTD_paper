The .ptraj scripts were run using CPPTRAJ of Amber 24. They produce radius of gyration data files, which are used in both the 
Jupyter Notebooks and Python scripts.

The Jupyter Notebooks produce the radius of gyration histograms, and the Pythons scripts produce the radius of gyrations vs. % Pro in *cis* conformation plots, 
which also use dihedral angles produced in the turn_and_cis/ folder.
