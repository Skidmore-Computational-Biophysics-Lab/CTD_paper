The .ptraj scripts were run using CPPTRAJ from Amber 24. 
They record solvent-accessible surface area (SASA) for the entire CTD peptide, and the SASA for each residue in the peptide.

The Jupyter Notebooks use data generated from the .ptraj scripts in this folder as well as .ptraj scripts for calculating
the dihedral angles for each residue from the turn_and_cis/ folder.
