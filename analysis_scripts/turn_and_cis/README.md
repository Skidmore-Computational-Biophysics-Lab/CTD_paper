The *turn.ptraj scripts produce files that contain the secondary structures of each residue in the CTD at each frame. Only the turn 
secondary structure is revelant for our Jupyter Notebooks.

The *dihedral_angle.ptraj scripts produce Phi, Psi, and Omega angle data for each residue and frame of the structure, though only the Pro 
residue Omega angles are relevant for our Jupyter Notebooks.

Turn percentage and frame weights data from the ctd_turn-pro13cis* notebooks were converted into .csv files for use in the avg_turn_percentage_full_peptide.ipynb 
Jupyter Notebook.
